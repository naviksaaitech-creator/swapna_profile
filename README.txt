# Swapna Yabaluri Portfolio

This is an unpublished static website package. The headline is "Learning, Building, and Shaping the Future with AI." Netra is intentionally not mentioned.

## Publish with Vercel
1. Extract this ZIP.
2. Create/sign in to a Vercel account at https://vercel.com/
3. Import a GitHub repository containing `index.html` and the `assets` folder, or use Vercel's supported CLI deployment workflow.
4. Deploy the static site. Vercel will provide a public URL you can share.
5. Open the URL and review the live site before sharing it.

The site uses a relative photo path: `assets/swapna-profile.png`.
